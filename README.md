# إنسانٌ وآلة · Human × Machine

**معرض بصري من 36 لوحة عن عصر الذكاء الاصطناعي** — كاريكاتير تحريري، حفر كلاسيكي بلون سيبيا، وفن سريالي.
A 36-plate bilingual gallery (Arabic / English) on AI, labour, art and power.

---

## المحتوى · What's inside

| | |
|---|---|
| `index.html` | الصفحة كاملة: معرض + عارض صور، بلا أي اعتماديات خارجية (single file, no dependencies) |
| `assets/thumb/` | 36 نسخة عرض بعرض 720px — تُستخدم في الشبكة (grid thumbnails) |
| `assets/full/` | 36 نسخة بعرض 1700px — تُستخدم في العارض (lightbox) |
| `*.jpeg` | الصور الأصلية عالية الدقة (original full-resolution plates) |
| `_rename-manifest.csv` | سجل إعادة التسمية: الاسم الأصلي ← الاسم الوصفي (rename log) |

## المزايا · Features

- **ثنائي اللغة بالكامل** — تبديل فوري بين العربية والإنجليزية مع قلب الاتجاه `rtl / ltr`، وحفظ التفضيل.
- **شبكة معرض متجاوبة** — 3 / 2 / 1 عمود، بترتيب قراءة منتظم ومساحات محجوزة مسبقاً (لا قفز في التنسيق).
- **تصفية وبحث** — حسب الأسلوب الفني، وبحث نصّي بالعربية والإنجليزية والوسوم معاً.
- **عارض صور كامل** — تنقّل بالأسهم ولوحة المفاتيح، سحب باللمس، عزر تنزيل، مشاركة رابط للوحة (`#p=12`).
- **يعمل بلا إنترنت** — لا خطوط أو سكربتات خارجية، ويمكن نشره كما هو على أي استضافة ثابتة.

## التشغيل · Run locally

```bash
# الأسهل: افتح الملف مباشرة
open index.html

# أو عبر سيرفر محلي
python3 -m http.server 8000
# ثم: http://localhost:8000
```

## الروابط · URL parameters

| الرابط | الوظيفة |
|---|---|
| `?lang=en` | فتح الصفحة بالإنجليزية مباشرة |
| `#p=14` | فتح اللوحة رقم 14 في العارض |
| `?lang=en#p=14` | دمج الاثنين |
